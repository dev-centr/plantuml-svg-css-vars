= plantuml-svg-css-vars

Post-process PlantUML/Kroki SVG into Themed SVG (adaptive + host) with webCompatibility normalization.
endif::[]

== About The Project

PlantUML adapter for the generator-neutral https://github.com/dev-centr/themed-svg[Themed SVG] standard.
Sibling of https://github.com/dev-centr/mermaid-svg-css-vars[`@dev-centr/mermaid-svg-css-vars`].

Kroki/PlantUML already emit SVG. This package:

. Normalizes the SVG for responsive web embedding (`width="100%"`, `preserveAspectRatio="xMidYMid meet"`, `themed-svg-root`).
. Applies an explicit Themed SVG manifest (sequence or component selector profiles included).
. Emits **standalone-adaptive** (bundled light/dark + `prefers-color-scheme`) and **host** (manual site toggle via runtime inline) outputs.

Package: `@dev-centr/plantuml-svg-css-vars`

Antora sites are a primary *consumer* (compose with Kroki in CI). This package is **not** Antora-specific — do not fork it into an Antora org to express that importance.

== Installation

[source,bash]
----
pnpm add @dev-centr/plantuml-svg-css-vars
----

Until the package is on the npm registry (first publish needs a Trusted Publisher entry for this new package name under the `@dev-centr` org on npmjs.com), install from the git tag:

[source,bash]
----
pnpm add github:dev-centr/plantuml-svg-css-vars#v0.1.0
----

After registering Trusted Publishing for `@dev-centr/plantuml-svg-css-vars` → GitHub `dev-centr/plantuml-svg-css-vars` workflow `Publish to npm`, re-run the `v0.1.0` tag workflow (or bump and tag).

== Usage

[source,ts]
----
import {
  prepareThemedPlantumlSvgDualOutput,
  plantumlSequenceBindings,
} from '@dev-centr/plantuml-svg-css-vars';

const result = prepareThemedPlantumlSvgDualOutput(krokiSvg, manifest);
----

CLI:

[source,bash]
----
# After Kroki/local PlantUML renders diagram.raw.svg
plantuml-svg-css-vars --manifest diagram.theme.json --dual-output \
  --output diagram.svg --host-output diagram.host.svg diagram.raw.svg
----

Helper profiles: `plantumlSequenceBindings()`, `plantumlComponentBindings()`, `plantumlBindingsForSvg(svg)`.
